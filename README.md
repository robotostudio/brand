# Roboto Studio brand-monorepo

The central home for Roboto Studio's brand and design: shared rules, guidance for applying them across digital formats, approved assets and reusable templates.

**Status:** Initial skeleton with shared brand rules imported from [robotostudio.com/design.md](https://robotostudio.com/design.md). Folder READMEs remain placeholders.

## Repository map

```text
brand-monorepo/
├── design.md               # Shared brand rules
├── README.md               # Repository map and getting started
├── systems/                # Specialised execution guidance
│   ├── voice/
│   └── motion/
├── assets/                 # Approved files ready to use
│   ├── shared/
│   └── motion/
└── templates/              # Reusable starting points
```

## Start here

1. Read [design.md](design.md) for the shared brand foundation.
2. As content is added, follow the relevant [system](systems/), starting with [voice](systems/voice/) or [motion](systems/motion/).
3. Use [approved assets](assets/) and [templates](templates/) as they become available.

## Where things belong

| Content | Home |
| --- | --- |
| A rule that applies across the brand | [design.md](design.md) |
| Instructions for a discipline, channel or format | [systems/](systems/) |
| An approved file someone can use in production | [assets/](assets/) |
| A reusable starting point someone can copy and adapt | [templates/](templates/) |

Systems and templates build on `design.md`. Link to shared rules instead of duplicating them. Document format-specific adaptations in the relevant system and resolve conflicts with the shared guidance.

Folder READMEs contain brief placeholders for future content.
