# Shared assets

Approved files used across formats.

- `logo/`: R mark (dark, light, pink) and wordmark (dark, light) as SVG, from [robotostudio.com/brand](https://robotostudio.com/design). "Dark" files go on dark backgrounds. Usage rules are in [design.md](../../design.md#logo).
- `fonts/`: Geist and Geist Mono, regular (400) and medium (500), as woff2 from the `geist` npm package v1.8.2. SIL Open Font License, in `fonts/OFL.txt`. Load them locally rather than from Google Fonts so renders work offline.
