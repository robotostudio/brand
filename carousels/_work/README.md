# Working decks

Cloud agents build a carousel here: `carousels/_work/<yyyy-mm-slug>/` with `spec.json`, `caption.md` and `img/`. The render goes in `out/` (`01.png` …, `carousel.pdf`, `preview.png`, generated `deck.html`).

Everything in this folder except this README is git-ignored. Do not commit a deck. Copy the PNGs, the PDF and `caption.md` to the artifacts folder instead. Steps: [systems/linkedin-carousel/CLOUD.md](../systems/linkedin-carousel/CLOUD.md).

`carousels/2026-10-content-model/` is the tracked reference deck. It is not a working folder.
